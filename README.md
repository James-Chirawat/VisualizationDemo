# RouteLens — Visualization Demo

เว็บสาธิตสอบสอน Data Visualization สำหรับติดตามการขนส่ง ใช้ Next.js App Router, TypeScript, Tailwind CSS, คอมโพเนนต์แบบ shadcn/ui (Radix), Recharts และ Lucide React

## เริ่มใช้งาน

ใช้ Node.js 22 ขึ้นไป

```sh
npm ci
cp .env.example .env.local
npm run dev
```

เปิด http://localhost:3000
ตรวจ TypeScript ด้วย `npm run typecheck` หรือสร้าง production build ด้วย `npm run build` แล้วเปิดด้วย `npm start`

## เชื่อม Qwen3.8-Flash

ใส่ API key ใน `.env.local` แล้วรีสตาร์ตเซิร์ฟเวอร์

```dotenv
QWEN_API_KEY=
QWEN_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen3.8-flash
```

รองรับชื่อ `DASHSCOPE_API_KEY` ด้วย ค่าเริ่มต้นเป็น endpoint Singapore ให้เปลี่ยน `QWEN_BASE_URL` ให้ตรงกับ region หรือ workspace ที่ออก key ใน [คู่มือ Alibaba Cloud Model Studio](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions) คีย์อยู่ฝั่งเซิร์ฟเวอร์ใน `/api/chat` และไฟล์ `.env.local` ถูกละเว้นจาก Git เมื่อยังไม่มีคีย์ แชตจะใช้คำตอบสาธิตที่คำนวณจากข้อมูล และแสดงป้ายแยกจากคำตอบ Qwen

สำหรับการนำเสนอผ่านเว็บ ให้ตั้ง environment variables บนโฮสต์ที่รองรับ Next.js server และจำกัดผู้เข้าถึงเดโมตามผู้ชมที่ต้องการ ค่าใช้จ่าย API เกิดขึ้นเฉพาะเมื่อเปิดใช้คีย์และส่งคำถาม

## ลำดับสาธิต

1. เริ่มทุกเส้นทาง เห็น 150 เที่ยว ส่งตรงเวลา 114 จาก 144 เที่ยวที่ส่งถึงแล้ว (79.2%) ค่าใช้จ่ายรวม 590,751 บาท
2. คลิกแท่งหรือปุ่ม **R-02** หน้าจอเปลี่ยนเป็น 21 เที่ยว โดยส่งถึงแล้ว 20 เที่ยว ตรงเวลา 11 เที่ยว (55%) และล่าช้า 9 เที่ยว
3. ดูสาเหตุที่บันทึกและตัวอย่างคนขับ เปิดเที่ยวที่ส่งช้าจากตารางเพื่อเทียบวันกำหนดกับวันส่งถึงจริง
4. เปิด **AI Analyst** แล้วถาม “ทำไมส่งล่าช้า และควรตรวจอะไรต่อ?” เซิร์ฟเวอร์คำนวณข้อมูลจากตัวกรองที่ส่งมา และส่งสถิติสรุปให้ Qwen
5. เปลี่ยนช่วงวันที่หรือสถานะ ตรวจว่ากราฟ ฐานคำนวณ และรายการเปลี่ยนตาม แล้วกดส่งออก CSV สำหรับช่วงที่เลือก

ข้อมูล 150 แถวเป็นข้อมูลจำลองคงที่ สร้างเพื่อให้สาธิตการกรองและดูรายละเอียดได้ในตัว เลข KPI หลักและ R-02 อ้างกรณีจากสไลด์ ส่วนตัวเลขรายเส้นทางและรายการอื่นคำนวณจากข้อมูลจำลองในเว็บตามจริง ตัวกรองวันที่ใช้วันที่สั่ง อัตราตรงเวลานับเฉพาะเที่ยวที่ส่งถึง ค่าใช้จ่ายเฉลี่ยนับทุกเที่ยวในตัวกรอง และวันล่าช้าเฉลี่ยนับเฉพาะเที่ยวที่ล่าช้า
